# earthquake_insights
🌍 Earthquake Analysis Dashboard – USGS Data (30 SQL Insights)

The Earthquake Analysis Dashboard is a data analytics project developed using Python, Streamlit, MySQL, and SQL to analyze global earthquake data retrieved from the USGS (United States Geological Survey) API. The system collects and stores more than five years of earthquake records, including details such as magnitude, depth, location, reporting network, tsunami alerts, and event type.

The project begins with automated data extraction from the USGS API, followed by data cleaning and structured storage in a MySQL database. A well-designed relational table schema ensures efficient querying and analysis. The dashboard interface, built using Streamlit, allows users to interactively select and execute from 30 advanced SQL queries designed to uncover meaningful seismic insights.

These queries analyze earthquake patterns such as the strongest and deepest earthquakes, yearly and monthly trends, day and hour distribution, tsunami-triggered events, regional activity levels, shallow-to-deep earthquake ratios, and alert classifications. Advanced analytical techniques including grouping, aggregation, window functions (LAG), conditional logic, and geographic distance calculations are used to generate deeper insights, such as year-over-year growth rates and consecutive earthquakes occurring within 50 km and one hour.

The application provides real-time query execution, interactive result tables, and CSV export functionality for further analysis. This project demonstrates strong skills in API integration, database design, advanced SQL analytics, and interactive dashboard development, making it a comprehensive end-to-end data engineering and data analysis solution.
